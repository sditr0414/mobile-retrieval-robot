# 스마트폰 앱

Flutter로 만든 Android용 로봇 제어 앱입니다. HC-05와 Bluetooth Classic
SPP로 연결해 차량, 로봇팔과 티칭 시퀀스를 제어합니다.

## 준비와 실행

Flutter SDK를 설치하고 의존성을 받은 뒤 실행합니다.

```powershell
cd app
flutter pub get
flutter run
```

Android 설정에서 HC-05를 먼저 페어링한 뒤 앱의 `기기 찾기`에서 연결합니다.
앱을 처음 실행할 때 Android가 요청하는 근처 기기 또는 위치 권한을 허용해야
페어링된 장치를 읽을 수 있습니다.
서보와 모터를 움직이기 전에 구동부 외부 전원과 STM32의 GND가 공통인지
확인합니다.

## 화면

- `RC카 주행`: 차동 조향 조이스틱과 E-STOP
- `로봇팔 조종`: 출력 활성화 확인 후 Base부터 Gripper까지 6개 채널 수동 제어
- `티칭 시스템`: 12개 시퀀스, 시퀀스당 최대 30개 웨이포인트

연결 직후에는 E-STOP 해제 확인이 필요합니다. 주행 화면은 100 ms마다 현재
조이스틱 값을 보내며, E-STOP은 해제 명령 전까지 잠깁니다. 로봇팔은 부팅 직후
출력이 꺼져 있으며 사용자가 명시적으로 활성화해야 합니다. 채널 1~4는
관절별 보정값을 사용하며 Wrist Tilt만 `500/1500/2500 us` 임시 범위이므로
수동 보정한 뒤 실측값으로 교체해야 합니다.
Base부터 Wrist Rotate까지는 중앙을 `0도`로 하는 `-90~+90도`로 표시합니다.
Gripper는 `0%` 최대 열림, `100%` 최대 닫힘으로 표시합니다. Base와 Gripper는
조립 방향에 맞춰 펌웨어에서 반대로 출력합니다. `홈 자세로 활성화`를 누르면
관절은 `0도`, Gripper는 최대 열림인 `0%`로 설정됩니다. `+` 또는 `-`를 짧게 누르면
1도 또는 1% 이동하고, 길게 누르면 120 ms마다 조금씩 목표값이 변합니다.

티칭 업로드는 한 번에 하나만 실행하며 패킷을 순서대로 전송한 뒤 STM32의
Flash 저장 ACK를 확인합니다.

## 패킷

앱이 기준이며 모든 명령과 ACK는 고정 11바이트입니다.

```text
[0xAA, Mode, Data0, Data1, Data2, Data3, Data4, Data5, Data6,
 Checksum, 0x55]
```

세부 명령은 `docs/protocol/bluetooth-protocol.md`를 확인합니다.
