# Flutter 제어 앱

HC-05 Bluetooth Classic SPP로 STM32를 제어하는 Android 앱입니다.

## 실행

스마트폰에서 HC-05를 먼저 페어링합니다.

```powershell
cd app
flutter pub get
flutter run
```

Android Bluetooth 권한, 외부 구동 전원, 공통 GND와 로봇 작업 공간을 먼저
확인합니다.

## 화면

| 화면 | 기능 |
|---|---|
| 차량 | 조이스틱, 전용 시퀀스, PID 설정·상태 |
| 로봇팔 | 6채널 수동 제어, 속도, 원점 보정 |
| 티칭 | 웨이포인트 편집, Flash 업로드·재생·초기화 |

연결과 STOP은 모든 화면에서 접근할 수 있습니다. 세로 화면은 아래쪽, 가로
화면은 왼쪽 탐색 메뉴를 사용합니다.

## 최초 연결

1. HC-05에 연결합니다.
2. 초기 STOP 잠금을 사용자 확인 후 해제합니다.
3. 로봇팔 화면에서 `원점으로 이동`을 눌러 출력을 활성화합니다.
4. 실제 원점 도착을 눈으로 확인합니다.
5. 차량 화면 진입 시 티칭 시퀀스 9가 완료될 때까지 기다립니다.

일반 서보에는 위치 피드백이 없습니다. 앱의 값은 실측 위치가 아니라 마지막
명령입니다. 로봇팔 ACK가 10초 동안 없으면 앱은 STOP을 요청합니다.

## 차량

- 조이스틱 입력 중 약 100 ms마다 명령 전송.
- 손을 떼면 정지. 펌웨어는 500 ms 타임아웃 적용.
- 차량 화면 진입 시 이동 자세인 시퀀스 9 재생.
- 이동 자세 실행 중 그리퍼는 현재값 유지.

| 시퀀스 | 용도 | 조건 |
|---:|---|---|
| 9 | 이동 자세 | 차량 화면 진입·이동 요청 |
| 10 | 잡기 위치 | 독립 실행 |
| 11 | 잡기 | 시퀀스 10 완료 후 |
| 12 | 놓기 | 시퀀스 11 완료 후 |

시퀀스 9~12는 이름을 바꿀 수 없으며 잠금 아이콘과 용도별 색으로 구분합니다.
시퀀스 11 뒤 첫 주행과 시퀀스 12 완료 뒤에는 그리퍼를 유지한 이동 자세를
먼저 실행합니다. 실제 자세는 티칭 후 Flash에 업로드합니다.

PID는 차량 화면 팝업에서 저장·활성화합니다.

- Kp `0.00~2.55`, Ki/Kd `0~100`.
- 초기값 `2.00/1.40/0.00`.
- MPU6050 보정 완료와 STOP 해제 후 활성화 가능.
- 회전에는 적용하지 않고 직진·후진 구간의 상대 Yaw만 유지.
- ACK의 실제 적용 상태만 `PID 적용 중`으로 표시.
- 목표·현재 Yaw, 오차, 출력, 좌우 PWM과 온도를 표시.
- 상태가 1.5초 이상 갱신되지 않으면 수신 대기로 표시.

## 로봇팔

| 대상 | 표시 범위 |
|---|---:|
| Base~Wrist Rotate | `-90~+90°` |
| Gripper | 열림 `0%`~닫힘 `100%` |
| 속도 | `50~100%` |

원점은 5관절 `0°`, Gripper `0%`입니다. 이동은 20 ms S-curve를 사용합니다.
슬라이더 트랙 탭은 값이 순간 이동하지 않으며 `-`/`+`는 짧게 누르면 한 단계,
300 ms 이상 누르면 연속 조정합니다.

### 원점 보정

1. `원점 보정`을 누르고 전체 원점 이동 ACK를 기다립니다.
2. Base부터 Gripper까지 한 관절씩 선택합니다.
3. 일반 관절은 `-90/0/+90°`, Gripper는 열림/닫힘 펄스를 조정합니다.
4. `확인 시퀀스`로 시험합니다.
5. `원점 보정 저장`으로만 Sector 7에 기록합니다.

| 대상 | 펄스 범위 |
|---|---:|
| Base~Wrist Rotate | `350~2650 µs` |
| Gripper | `1000~2000 µs` |

보정 중 다른 관절은 원점을 유지하고 차량은 잠깁니다. 자세와 실측값은
[서보 보정 문서](../docs/hardware/servo-calibration.md)를 기준으로 합니다.

## 티칭

- 12개 시퀀스, 시퀀스당 최대 30개 웨이포인트.
- 시퀀스 1~8은 UTF-8 21바이트 이하 이름을 지정해 웨이포인트와 함께 저장.
- 시퀀스 9~12는 이동 자세·잡기 위치·잡기·놓기 고정 이름 사용.
- 로봇팔 화면에서 현재 자세를 앱 목록에 추가·삭제.
- 티칭 화면에서 각도 수정, 편집본 재생과 Flash 저장·초기화.
- HC-05 연결 후 티칭 화면에 들어가면 저장된 시퀀스 이름을 불러옴.
- 업로드·초기화 중 화면 전환과 데이터 수정 잠금.
- 미저장 편집본은 시퀀스 변경 또는 앱 종료 시 폐기.
- 성공 ACK를 받은 뒤에만 저장·초기화 완료로 표시.
- 저장·초기화 완료 안내 전에는 앱을 종료하거나 로봇 전원을 끄지 않음.
- `시퀀스 재생`은 현재 편집본을 임시 전송하므로 Flash 저장 없이 바로 반영.
- 저장하지 않고 다른 시퀀스를 고르면 변경을 버리고 선택한 Flash 원본을 자동 조회.
- 차량 화면의 이동·잡기 위치·잡기·놓기는 편집본이 아닌 Flash 저장본 재생.

## TEST 모드

화면 제목을 길게 눌러 Bluetooth 없는 기능 확인 모드를 켭니다. 실제 패킷이나
Flash를 변경하지 않으며 실제 Bluetooth 연결 중에는 시작할 수 없습니다.

## 프로토콜과 점검

패킷은 고정 16바이트입니다. 바이트 규격은
[Bluetooth 프로토콜](../docs/protocol/bluetooth-protocol.md)을 따릅니다.

```powershell
cd app
flutter analyze
flutter test
flutter build apk --debug
```

`flutter_classic_bluetooth 0.1.8`은 현재 빌드되지만 Kotlin Gradle 적용 경고가
있습니다. Flutter가 해당 방식을 제거하기 전에 대체 플러그인을 실기기에서
검증합니다.
