# MPU6050 상대 Yaw PID 제어

이 문서는 MPU6050으로 계산한 상대 Yaw를 이용해 4WD 차량의 직진·후진 방향을
보정하는 과정을 설명합니다. 수식과 제한값은 현재 펌웨어를 기준으로 합니다.

![전체 시스템 다이어그램](system-diagram.png)

## 제어 목적

좌우 모터에 같은 PWM을 주어도 모터 편차, 바닥 마찰, 하중과 무게중심 때문에
차량은 한쪽으로 치우칠 수 있습니다. PID는 주행 시작 방향을 목표 Yaw로 저장하고,
현재 Yaw와의 차이로 좌우 PWM을 반대로 보정합니다.

```text
조이스틱 직진·후진 입력
  → 현재 Yaw를 목표로 저장
  → MPU6050 Z축 각속도 측정
  → 상대 Yaw 적분
  → 목표와 현재 Yaw의 오차 계산
  → PID 출력 계산
  → 좌우 PWM에 반대 부호로 적용
```

이 제어는 목표 지점이나 절대 방위를 찾아가는 PID가 아닙니다. MPU6050에는
자력계가 없으므로 한 번의 직진·후진 구간에서 시작 방향을 유지하는 용도입니다.

## 센서 값 생성

1. `WHO_AM_I`로 MPU6050 계열 센서 확인.
2. 가속도 ±2g, 자이로 ±250 dps 설정.
3. 차량을 정지한 상태에서 3초간 자이로 Bias 계산.
4. 20 ms마다 센서 측정.
5. Bias 제거 후 dps로 변환.
6. 2 Hz 1차 저역통과 필터 적용.
7. Z축 `±0.15 dps` deadband 적용.
8. Z축 각속도를 시간 적분해 상대 Yaw 계산.
9. Yaw를 `-180~+180°`로 정규화.

```text
Yaw(k) = Yaw(k-1) + GyroZ(k) × Δt
```

센서의 상세 연결과 필터는 [MPU6050 문서](imu.md)를 참고합니다.

## 앱에서 PID를 켜는 과정

```text
PID 설정 조회
  → 차량 정지
  → 3초 IMU 영점 보정 요청
  → 보정 완료 ACK 확인
  → PID 활성화 요청
  → 활성화 ACK 확인
  → 새 주행 명령 허용
```

- 초기 계수: `Kp=2.00`, `Ki=1.40`, `Kd=0.00`.
- 앱 설정 범위: Kp `0.00~2.55`, Ki/Kd `0~100`.
- Kp는 `0.01`, 저장값은 모든 계수를 1,000배한 정수 단위로 전송합니다.
- 계수는 Sector 7에 저장하지만 PID 활성 상태는 저장하지 않습니다.
- PID는 부팅 후 자동으로 켜지지 않습니다.
- 실행 중 계수를 바꾸지 않고 PID를 끈 뒤 저장합니다.

IMU 사용 불가, 보정 중, Flash 작업 중, 로봇팔 이동 중 또는 E-STOP 상태에서는
PID 활성화를 거부합니다. 상태 전환 중에는 모터를 먼저 정지하고 이전 주행 명령을
버리며, 전환 뒤 들어온 새 주행 명령만 사용합니다.

## 직진 판정

앱은 조이스틱 X축이 중앙 범위에 있고 전진·후진 입력이 있을 때만 좌우 PWM을
같게 만들고 `PidStraight=1`을 전송합니다.

- 기본 중앙 범위: `|X| ≤ 0.10`.
- 앱 설정 범위: `0.00~1.00`.
- PID 직진 상태 유지 범위: 설정값 `+0.04`.
- 전진·후진 입력 최소 조건: `|Y| > 0.05`.

`+0.04` 히스테리시스는 경계 부근의 작은 손 떨림 때문에 PID가 반복해서
켜졌다 꺼지는 현상을 줄입니다. 이 범위는 앱 실행 중에만 유지되며 STM32 Flash에
저장하지 않습니다.

펌웨어에서 PID가 실제 계산되려면 다음 조건을 모두 만족해야 합니다.

- PID 활성화 완료.
- IMU 사용 가능.
- `PidStraight=1`.
- 좌우 방향이 동일.
- 좌우 PWM 중 하나 이상이 0보다 큼.
- 유효한 새 주행 명령이 500 ms 안에 수신됨.
- 차량 인터록이 해제됨.

## 목표 Yaw

직진 PID가 새로 시작되거나 전진·후진 방향이 바뀌면 다음 IMU 샘플의 Yaw를
목표값으로 저장합니다. 앱이 `RefreshYaw=1`을 보낸 경우에도 목표를 갱신합니다.

```text
목표 Yaw = 직진·후진 구간 시작 시점의 현재 Yaw
```

목표를 갱신할 때 적분항, 이전 오차와 이전 샘플 시간을 초기화합니다. 회전 후 다시
직진하면 회전 전 방향이 아니라 새 방향이 목표가 됩니다.

## PID 계산

### 방향 오차

```text
오차 e(k) = 목표 Yaw - 현재 Yaw
```

오차는 가장 짧은 회전 방향이 되도록 `-180~+180°`로 변환합니다. 예를 들어
목표가 `179°`, 현재가 `-179°`이면 단순 차이 `358°`가 아니라 `-2°`를 사용합니다.

### 샘플 시간

```text
Δt = (현재 샘플 시각 - 이전 샘플 시각) / 1000
```

정상 주기는 약 20 ms입니다. 첫 샘플, 같은 시각 또는 200 ms를 넘긴 비정상 간격은
`Δt=0.02 s`, 미분항 0으로 처리해 큰 순간 미분값을 막습니다.

### P, I, D 항

```text
P = Kp × e(k)
I상태 = I상태 + Ki × e(k) × Δt
D = Kd × (e(k) - e(k-1)) / Δt

PID 출력 = P + I상태 + D
```

| 항 | 역할 | 현재 운용 의미 |
|---|---|---|
| P | 현재 오차에 즉시 반응 | 한쪽으로 틀어진 만큼 바로 좌우 PWM 차이 생성 |
| I | 누적되는 작은 오차 보정 | 지속적인 모터 편차와 하중 차이 보정 |
| D | 오차 변화 속도 억제 | 진동 완화용, 초기값은 0 |

적분 상태는 `±50`, 최종 PID 출력은 `±80 PWM`으로 제한합니다. 적분 제한은
모터 출력이 포화된 동안 값이 계속 쌓이는 wind-up을 줄입니다.

## 좌우 PWM 적용

현재 장착 방향은 보정 부호 `-1`을 사용하며 후진에서는 부호를 다시 뒤집습니다.

```text
보정값 = -PID 출력
후진이면 보정값 = -보정값

왼쪽 PWM  = 기본 왼쪽 PWM  + 보정값
오른쪽 PWM = 기본 오른쪽 PWM - 보정값
```

최종 값은 `0~255`로 제한합니다. 앱의 조이스틱 출력은 최대 `220 PWM`으로 제한해
PID가 한쪽 PWM을 올릴 여유를 둡니다. 다만 최대 증가 여유는 35이므로 큰 보정은
한쪽이 255에서 포화될 수 있습니다. 반대쪽 PWM을 낮추는 보정은 계속 적용됩니다.

Canva의 예시처럼 기본 PWM이 198이고 계산된 좌우 보정 크기가 17.89라면 한쪽은
약 180, 반대쪽은 약 216이 됩니다. 실제 어느 쪽을 높이는지는 Yaw 오차, 장착 부호와
전진·후진 방향에 따라 결정됩니다.

## 초기화되는 조건

다음 상황에서는 목표 Yaw와 PID 누적 상태를 버립니다.

- 차량 정지 또는 Engine OFF.
- 조이스틱 회전 입력.
- 전진·후진 방향 변경.
- E-STOP 설정·해제.
- 500 ms 통신 타임아웃.
- 로봇팔 이동, 티칭, Flash 작업 또는 IMU 보정 인터록.
- IMU 오류와 재연결.
- PID 활성화·비활성화 전환.

인터록 해제 전에 받은 주행 명령은 다시 사용하지 않습니다. 새 패킷이 들어와야
모터와 PID가 재개됩니다.

## 앱 상태 표시

펌웨어는 약 500 ms마다 PID 상태를 16바이트 패킷으로 보냅니다.

- 명령 수신 여부.
- PID 설정 활성 여부와 실제 연산 중 여부.
- 전진·후진 상태.
- 목표 Yaw, 현재 Yaw와 오차.
- PID 출력.
- 최종 좌우 PWM.
- IMU 사용 가능 상태.

앱은 1.5초 이상 상태가 오지 않으면 이전 값을 현재 상태처럼 표시하지 않고
수신 대기로 전환합니다. 정확한 바이트 배열은
[Bluetooth 프로토콜](../protocol/bluetooth-protocol.md)을 기준으로 합니다.

## 튜닝 순서

1. 차량을 들어 올리거나 넓고 안전한 시험 공간을 확보합니다.
2. IMU 장착 방향과 3초 보정 성공을 확인합니다.
3. `Ki=0`, `Kd=0`에서 Kp를 작은 값부터 올립니다.
4. 방향 복귀가 충분하지만 진동하지 않는 Kp를 찾습니다.
5. 한쪽으로 계속 남는 작은 오차가 있을 때 Ki를 조금씩 올립니다.
6. 빠른 진동이나 과도 응답이 있을 때만 Kd를 소량 적용합니다.
7. 저속·중속·최대 220 PWM과 전진·후진을 각각 시험합니다.
8. 안정된 계수만 Flash에 저장합니다.

Yaw 자체가 자이로 적분값이라 노이즈가 포함됩니다. Kd를 크게 하면 미세한 오차
변화가 증폭될 수 있으므로 초기값은 0입니다.

## 문제 확인

| 증상 | 우선 확인 |
|---|---|
| PID 활성화 거부 | STOP, IMU 보정, 센서 상태, 로봇팔·Flash 인터록 |
| 한쪽으로 더 심하게 틀어짐 | IMU 장착 부호, 모터 전진 극성, 후진 부호 |
| 좌우가 빠르게 흔들림 | Kp·Kd 과다, IMU 진동, 조이스틱 직진 범위 |
| 시간이 지나며 보정이 커짐 | Ki 과다, 바닥 미끄러짐, Yaw drift |
| 최대속도에서 효과 감소 | 255 PWM 포화, 앱 220 제한 적용 여부 |
| 갑자기 PID가 멈춤 | 500 ms 명령 타임아웃, IMU 오류, 인터록 상태 |
