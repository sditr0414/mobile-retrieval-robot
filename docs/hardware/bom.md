## 전원

```text
서보용 2S → XL4015 → PCA9685 V+ → 서보 6개
차량용 2S ─────────→ L298N ─────→ 모터 4개
STM32 논리 전원 ───→ PCA9685 VCC
STM32 VIN DC-DC ───→ 실물 적용(모델·출력 미기록)
```

- 두 팩의 양극은 연결하지 않고 모든 장치의 GND만 공통으로 연결합니다.
- 서보 전류는 XL4015 OUT-, 모터 전류는 차량 배터리 음극으로 직접 귀환합니다.
- 고전류를 STM32 보드와 신호용 점퍼선에 통과시키지 않습니다.
- L298N ENA/ENB 점퍼는 제거하고 PA0/PA1 PWM을 연결합니다.
- BMS, 퓨즈와 물리 비상정지는 현재 구성에 없습니다.
- XL4015, STM32 VIN DC-DC와 MPU6050 전원은 실물에 적용되어 있으며 구체적인 값은 문서에 미기록 상태입니다.

제외 부품: 초음파 센서, 휠 엔코더, 자력계.
