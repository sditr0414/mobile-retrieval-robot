# MPU6050

## 연결

| MPU6050 | NUCLEO-F411RE |
|---|---|
| VCC | 실물 적용, 공급전압 문서 미기록 |
| GND | 공통 GND |
| SCL / SDA | PA8 / PC9 |
| AD0 | GND, 주소 `0x68` |
| INT | 미사용 |

MPU6050은 I2C3 100 kHz와 전용 `imuI2cMutex`를 사용합니다. PCA9685의
I2C1과 분리되어 센서 버스 오류가 서보 통신에 영향을 주지 않습니다.

## 동작

1. 호환 센서 ID `0x68`, `0x70`, `0x71`, `0x73` 확인.
2. 가속도 ±2g, 자이로 ±250 dps 설정.
3. 정지 상태에서 3초 자이로 영점 보정.
4. 20 ms마다 측정하고 2 Hz 저역통과 필터 적용.
5. X/Y축 0.30 dps, Z축 0.15 dps deadband 적용.
6. Z축 각속도를 적분해 `-180~+180°` 상대 Yaw 생성.

PID를 켤 때도 차량을 먼저 정지하고 3초 영점 보정을 다시 수행합니다. 앱은 보정
완료 ACK를 받은 뒤 PID 활성화를 요청합니다.

센서 오류 시 1초마다 재연결합니다. 수동 차량·로봇팔·티칭은 유지하지만 PID를
끄고 차량을 정지한 뒤 새 주행 명령을 요구합니다.

## 방향 PID

- 직진·후진 시작 시 현재 Yaw를 목표로 저장.
- 회전에는 PID를 적용하지 않음.
- 장착 방향 보정 부호 `-1`, 후진 시 다시 반전.
- 적분항 `±50`, 최종 보정 `±80 PWM` 제한.
- 앱의 기본 주행 PWM은 최대 `220`; 펌웨어 PID 출력은 `0~255` 범위에서 보정.
- 정지, 회전, 방향 전환, E-STOP, 타임아웃과 인터록에서 상태 초기화.
- 초기 계수 `Kp=2.00`, `Ki=1.40`, `Kd=0.00`.

MPU6050에는 자력계가 없어 절대 Yaw를 보정하지 않습니다. 온도는 앱 표시용이며
보정에는 사용하지 않습니다. 장착 방향과 필터·PID 계수는 실제 차체에서 다시
확인합니다.
