# 협업 도구 안내

## 바로가기

| 도구 | 용도 |
|---|---|
| Slack | 질문, 당일 진행 상황, 빠른 의사소통 |
| GitHub | 코드, 문서, Issue, Pull Request |
| Notion | 확정 설계, 부품, 담당, 일정, 시험 결과 |

## 기록 기준

- 코드의 최신 원본: GitHub
- 설계와 일정의 최신 원본: Notion
- 빠른 대화와 질문: Slack
- 해야 할 일과 오류 추적: GitHub Issue

## 권장 작업 흐름

1. 작업 전 Issue와 Slack을 확인합니다.
2. `develop`을 최신 상태로 받고 개인 브랜치를 만듭니다.
3. 변경 사항을 Commit하고 Push합니다.
4. Pull Request를 만들고 팀원 검토를 요청합니다.
5. 확정된 설계·측정값은 Notion에 반영합니다.
